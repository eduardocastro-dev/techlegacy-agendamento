# TechLegacy Agendamento

Sistema de agendamento para pequenos estabelecimentos.

## Objetivo

Permitir que estabelecimentos configurem seus serviços e horários de atendimento e recebam agendamentos de clientes através de uma página pública.

## Stack

- Python 3.11
- Flask
- PostgreSQL 16
- SQLAlchemy
- Docker
- Pytest
